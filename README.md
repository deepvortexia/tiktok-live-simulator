# 📱 TikTok Live Simulator

Un simulateur de TikTok Live réaliste construit avec React + Vite.

![Preview](https://img.shields.io/badge/React-18-61dafb?logo=react) ![Vite](https://img.shields.io/badge/Vite-5-646cff?logo=vite) ![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Fonctionnalités

- 🔴 **Démarrer / Arrêter un live** avec bouton animé
- 👥 **Compteur de viewers** qui fluctue dynamiquement
- 💬 **Commentaires automatiques** de faux utilisateurs en temps réel
- ❤️ **Système de likes** avec cœurs flottants animés
- 🎁 **Cadeaux aléatoires** (Rose, Lion, Fusée, Univers) avec notifications
- 🪙 **Total de pièces** accumulées pendant le live
- ⏱ **Timer** du live en cours
- 📱 **Interface Phone Frame** réaliste

## 🚀 Installation

```bash
# Cloner le repo
git clone https://github.com/TON_USERNAME/tiktok-live-simulator.git
cd tiktok-live-simulator

# Installer les dépendances
npm install

# Lancer en développement
npm run dev
```

Ouvre [http://localhost:5173](http://localhost:5173) dans ton navigateur.

## 🏗️ Build production

```bash
npm run build
npm run preview
```
